HR Employee Attrition Analysis

Project Overview

This project focuses on analyzing employee attrition to understand workforce trends and identify factors associated with employee turnover.

The project uses Excel, Python, MySQL, and Power BI to perform data analysis and present meaningful insights through an interactive dashboard.

Project Objectives

- Analyze employee attrition patterns.
- Examine workforce distribution.
- Explore employee attrition across different departments.
- Analyze gender-wise attrition.
- Present key HR metrics through data visualization.
- Support data-driven HR decision-making.

Tools & Technologies

- Microsoft Excel: Data analysis and reporting.
- Python: Data analysis and data processing.
- MySQL: Database management and SQL queries.
- Power BI: Interactive dashboard and visualization.

Dataset Information

- Original dataset: 1,470 employee records.
- Employees who left: 237.
- Active employees: 1,233.
- Overall attrition rate: Approximately 16.12%.

Project Structure

- "HR-Employee-Attrition.csv" – Original dataset.
- "HR-Attrition-analysis.xlsx" – Excel analysis.
- "HR_EMPLOYEES_ATTRITION_ANALYSIS.ipynb" – Python analysis notebook.
- "HR_Employee_Attrition_Analysis.sql" – SQL queries.
- "HR-EMPLOYEE-ATTRITION-PROJECT.pbix" – Power BI dashboard.

Key Skills Demonstrated

- Data Cleaning
- Exploratory Data Analysis (EDA)
- SQL Queries
- Data Visualization
- Dashboard Development
- HR Data Analysis

Project Outcome

An end-to-end HR analytics project demonstrating how multiple data analysis tools can be used to explore employee attrition and communicate findings through an interactive Power BI dashboard.
